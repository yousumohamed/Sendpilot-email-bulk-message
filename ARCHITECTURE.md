## Data Flow

```
┌──────────────┐
│ User uploads │
│  CSV/Excel   │
└──────┬───────┘
       │
       ▼
┌──────────────────┐
│ Parse file with  │
│ Pandas/openpyxl  │
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ Extract emails   │
│ & placeholders   │
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ Validate emails  │
│ (regex check)    │
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ Create Campaign  │
│ & Email records  │
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ Background       │
│ Thread starts    │
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ For each email:  │
│ • Personalize    │
│ • Send via SMTP  │
│ • Wait 1 second  │
│ • Update status  │
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ Campaign         │
│ completed        │
└──────────────────┘
```
