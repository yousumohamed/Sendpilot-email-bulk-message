# Security Policy

## Reporting a Vulnerability

We take the security of Send Pilot seriously. If you have found a security vulnerability, please do not disclose it publicly until we have had a chance to fix it.

### How to Report

Please report security vulnerabilities through one of the following channels:

| Platform | Link | Response Time |
| :--- | :--- | :--- |
| **GitHub Security** | [Report a Vulnerability](https://github.com/yousumohamed/Sendpilot-email-bulk-message/security/advisories/new) | 48-72 hours |
| **Email** | [yousumoha255@gmail.com](mailto:yousumoha255@gmail.com) | 24-48 hours |
| **Contact Form** | [somali-music.vercel.app/contact](https://somali-music.vercel.app/contact) | 24-48 hours |
| **Discord** | [Join Server](https://discord.gg/hjhm4RtgP2) | Real-time |

### Response Process

1. **Receipt**: We will acknowledge receipt of your report within 24-48 hours.
2. **Evaluation**: We will investigate and verify the vulnerability.
3. **Fix**: We will work on a fix and test it.
4. **Disclosure**: We will coordinate with you on a public disclosure date.
